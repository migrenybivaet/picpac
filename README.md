# PicPac 📸

**PicPac** — это мобильное приложение-прототип для заказа фотопечати и создания фотокниг. Проект написан на Flutter и использует Supabase для синхронизации заказов и чатов поддержки в реальном времени между устройствами.

## ✨ Основные возможности

*   **Каталог продуктов**: Фотокниги (Classic, Lite, Premium) и быстрая фотопечать (от 10×15 до панорам).
*   **Редактор фотографий**: Наложение фильтров, рамок, создание коллажей (с функцией «Потрясти» для случайной раскладки).
*   **ИИ-Помощник**: Обработка голосовых/текстовых команд (например, «убери фон», «сделай ч/б», «обрежь квадратом»).
*   **Оформление заказа**: Выбор форматов, матовой/глянцевой бумаги, валидация белорусских номеров и адресов.
*   **Роли и доступ**:
    *   **Пользователь**: Создает проекты, оформляет заказы, пишет в поддержку.
    *   **Админ**: Видит новые заказы в реальном времени, подтверждает их, меняет статусы.
    *   **Поддержка**: Отвечает на тикеты клиентов.
*   **Push-уведомления**: Мгновенное оповещение пользователя при смене статуса заказа.
*   **Синхронизация**: База данных Supabase гарантирует, что заказ, созданный на одном телефоне, сразу появится в админке на другом.

## 🛠 Технологии

*   [Flutter](https://flutter.dev/) (Dart)
*   [Supabase](https://supabase.com/) (База данных PostgreSQL + Realtime)
*   [flutter_local_notifications](https://pub.dev/packages/flutter_local_notifications) (Локальные пуши)
