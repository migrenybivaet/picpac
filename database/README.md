# MySQL

`schema.sql` — только схема для MySQL Server 8.0.16+ / 8.4, не готовая БД с пользователями и не соединение с приложением. Она не тестировалась на реальном сервере и нуждается в миграциях и проверке перед использованием. Запуск на своей тестовой БД: `mysql -u <имя> -p < schema.sql` (вводите пароль в интерактивном приглашении; не добавляйте в код или ZIP).

Для подключения нужен промежуточный API: TLS, авторизация, роли, проверка владельца в каждом запросе, изоляция файлов, транзакции и уникальный ключ повторной отправки заказа. Напрямую из APK к MySQL подключаться нельзя. В текущем APK все данные остаются локальными. Перед переносом старых общих проектов необходимо явно определить их владельца; автоматически распределить их надёжно нельзя.
